description: Regenerate docs/ from src/ using the project's documentation generator
---

Run this project's documentation workflow in one step:

1. Run `npm run docs` from the repository root. This executes `scripts/generate-docs.js`, which walks `src/**/*.{js,jsx}`, analyzes the import graph via `scripts/docgen/graph.js`, and writes markdown into `docs/` via `scripts/docgen/render.js`.
2. Report how many files were generated (from the script's console output).
3. Read `docs/README.md` and tell the user which files, if any, are flagged `⚠` (orphaned / not imported anywhere from `src/main.jsx`), since that's the signal most likely to need their attention.

Do not hand-edit anything under `docs/` — it is entirely regenerated by this command.
